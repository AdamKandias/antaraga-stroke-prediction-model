Cara Kerja

Tiga langkah,
perlindungan penuh.

Dari sensor ke notifikasi keluarga — semuanya terjadi otomatis dalam hitungan milidetik.

01
Kenakan Smartband
Pasang ANTARAGA di pergelangan tangan. Sensor PPG MAX30102 dan SON1303 mulai merekam sinyal detak jantung secara otomatis setelah terhubung WiFi.
02
AI Analisis Sinyal
Model XGBoost menganalisis morfologi gelombang PPG dan vital sign tiap 1 detik untuk mendeteksi pola yang berkaitan dengan risiko stroke iskemik.
03
Notifikasi Keluarga
Jika risiko tinggi terdeteksi, push notification langsung dikirim ke HP keluarga beserta skor ABCD2 dan rekomendasi tindakan medis segera.
Fitur Utama

Teknologi wearable
untuk ketenangan keluarga.

Dirancang untuk kemudahan caregiver (pengawasan) terhadap lansia dari pemasangan hingga pembacaan hasil.

Pulse Wave Analysis (PWA)
Sinyal PPG mentah diproses dengan bandpass filter Butterworth (0.5–12 Hz) dan analisis morfologi: systolic peak, dicrotic notch, crest time, pulse width. Menghasilkan 23+ fitur kardiovaskular per siklus jantung untuk input model MLP.
Dashboard Monitoring Real-time
Dashboard web memvisualisasikan sinyal PPG mentah, setelah filter PWA, estimasi vital MLP, dan gauge risiko XGBoost. Semuanya diperbarui setiap detik.
Multi-profil Lansia
Satu akun keluarga memantau beberapa lansia sekaligus. Riwayat vital dan log prediksi tersimpan terpisah per profil.
Penilaian ABCD2 Terintegrasi
Formulir ABCD2 untuk menilai risiko TIA menjadi stroke penuh dalam 2, 7, dan 90 hari dengan rekomendasi tindakan klinis otomatis.
Teknologi AI

Model terlatih,
performa terukur.

ANTARAGA menggunakan dua model AI bertingkat: MLP untuk mengestimasi vital sign dari morfologi PPG, dan XGBoost untuk menilai risiko stroke dari profil vital. Keduanya berjalan dalam <15ms per prediksi.

Dataset: 5.110 rekaman klinis
